# Dayla Telegram bot

Telegram-чат с Dayla: планы, вопросы о расписании и напоминания для пользователей, которые привязали Telegram к аккаунту Dayla.

## Возможности

- планы обычным текстом, голосовыми, аудио и файлами PDF/DOCX — события сразу появляются в календаре Dayla;
- кнопки «↩️ Отменить» и «↗️ Открыть в Dayla» под созданными событиями;
- повторяющиеся события («каждую среду в 19:00 бассейн»);
- вопросы о расписании («что у меня завтра?», «когда у меня стоматолог?») и короткие ответы на обычные вопросы;
- `/today`, `/tomorrow`, `/week` и клавиатура «Сегодня / Завтра / Неделя / Напоминания / Помощь»;
- напоминания с кнопками «+10 мин» / «+1 час» и утренний план дня;
- `/reminders` — настройки напоминаний прямо в чате, `/unlink` — отвязать аккаунт.

## Как устроено

Бот не подключается к базе данных и не обращается к GigaChat. Всё это делает backend, а бот вызывает его API `/internal/bot/*` с заголовком `X-Bot-Token`. Сам бот только распознаёт голосовые сообщения и извлекает текст из документов, а также оформляет ответы.

Привязка: на сайте в «Настройки → Telegram» пользователь получает ссылку `t.me/<bot>?start=<код>`. До привязки бот показывает приветствие с инструкцией. При привязке события, созданные в старом режиме бота, переносятся в аккаунт Dayla.

## Настройка

Создайте `.env` по образцу `.env.example`:

```env
TOKEN=telegram-bot-token-from-botfather
BACKEND_URL=http://127.0.0.1:8000
BOT_API_TOKEN=same-value-as-backend
NOTIFICATION_POLL_SECONDS=20
```

`BOT_API_TOKEN` должен совпадать с `BOT_API_TOKEN` в `backend/.env`. Раз в `NOTIFICATION_POLL_SECONDS` бот забирает у backend уведомления и отправляет их.

Чтобы под ответами появилась кнопка «Открыть в Dayla», задайте на backend `PUBLIC_APP_URL` (адрес сайта, только `https://` — Telegram не принимает ссылки на localhost).

## Запуск

Вместе со всем проектом из корня репозитория:

```bash
docker compose up -d --build
```

Отдельно (backend должен быть запущен):

```bash
pip install -r requirements.txt
python -m bot.main
```

Запускайте только один экземпляр бота с одним токеном, иначе Telegram вернёт `TelegramConflictError`.
